# Reforge

> Reforge is the company behind Reforge Launch, a developer platform for feature flags, live configuration, dynamic log levels, and experimentation delivered as a service (formerly Prefab). Applications integrate via first-party SDKs (Node, JavaScript, React, Python, Ruby, Go, Java) and a CLI, evaluating flags and configuration against user context with server- and client-side SDK keys. Configuration is delivered over a global network (primary/secondary.reforge.com) with SSE and polling; telemetry flows to api.reforge.com. Backed by a16z and Insight Partners.

## Product

- [Reforge Launch docs](https://docs.reforge.com/): Feature flags, live config, dynamic log levels, experiments.
- [Get started (5 min)](https://docs.reforge.com/docs/tutorials/get-started): SDK key setup and first flag evaluation.
- [Node SDK docs](https://docs.reforge.com/docs/sdks/node)
